# UI / UX

## Identidad visual presente en las vistas

- Primario: `#63a20c`
- Secundario: `#113713`
- Fondo claro: `#f5f7f2` / `#f4f6f9`
- Tipografía de la landing: Inter
- Botones con radio amplio en la página pública; dashboard más compacto

## Chatbot

- Botón flotante inferior derecho.
- Panel `role="dialog"` con cierre por botón y tecla Escape.
- Aviso permanente de que es un asistente de IA y no reemplaza al docente ni a resultados oficiales.
- Sugerencias rápidas bilingües.
- Área de mensajes con `aria-live="polite"`.
- Tamaño táctil mínimo de controles de 44px.
- Estilos acotados al contenedor `.proudec-chatbot` para no romper CSS inline de las vistas actuales.
